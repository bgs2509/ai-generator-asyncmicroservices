# Checklists

This directory contains decision-support checklists for common framework tasks.

## Purpose

Checklists provide structured decision trees and step-by-step verification for tasks that require consistent application of framework rules.

## Contents

| Checklist | Purpose | Use When |
|-----------|---------|----------|
| [service-naming-checklist.md](./service-naming-checklist.md) | Naming convention decision tree | Creating new services |

## How to Use

Checklists are designed for quick reference during development:

1. Open the relevant checklist
2. Follow the decision tree or step list
3. Verify each item applies to your case
4. Document any deviations
